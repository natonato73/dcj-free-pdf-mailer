# DCJ Free PDF Mailer v1.6.0 運用ガイド

## 日常運用の流れ

1. 無料PDFを用意する
2. WordPressメディアライブラリへPDFをアップロードする
3. 管理画面でPDF設定を作成する
4. PDFごとに配信カテゴリを設定する
5. ショートコードを固定ページや投稿へ設置する
6. テスト送信でメール本文とPDFリンクを確認する
7. 購読者リストと送信ログを定期確認する
8. 必要に応じてメルマガテンプレートを作成し、プレビュー後に送信する

## 管理画面のジャンプリンクと折りたたみ

v1.7.0以降は、管理画面上部のリンクから「メール送信設定」「PDF設定一覧」「送信ログ」「購読者リスト」「メルマガ送信」「ダウンロードレポート」へ移動できます。

各セクション見出しをクリックすると、本文部分を開閉できます。開閉状態はブラウザに保存されるため、次回表示時も前回の状態を引き継ぎます。

## 無料PDF設定の作成手順

WordPress管理画面の **DCJ Free PDF** を開き、「新規PDF設定を追加」から設定します。

主に確認する項目:

- 管理ID
- 言語
- タイトル
- PDF URL
- メール件名
- メール本文
- 配信カテゴリ
- 有効/無効

PDF URLは、ブラウザで直接開けるURLを指定してください。公開前に必ず自分宛てにテスト送信し、PDFリンクが開けることを確認します。

## PDF設定0件時の扱い

v1.6.1以降は、PDF設定をすべて削除した状態を許可します。

PDF設定が0件の場合、管理画面には「PDF設定はまだありません。新規追加してください。」と表示されます。試験用または初期サンプルPDF設定は自動復活しません。

本番運用開始前にサンプル設定を削除した場合は、必要なPDF設定だけを新規追加してください。

## PDFごとの配信カテゴリ設定

PDF設定の「配信カテゴリ」で、そのPDFに関係するカテゴリを複数選択できます。

ユーザーが無料PDFを申し込み、メルマガ同意ありの場合、そのPDF設定の配信カテゴリが購読者タグとして自動付与されます。公開側フォームには配信カテゴリ選択欄は表示されません。

## 複数フォーム設置時の送信後位置

v1.6.2以降は、同じ記事や固定ページに複数の無料PDFフォームを設置している場合でも、送信後に送信元フォーム付近へ戻ります。

既存のショートコードは貼り替え不要です。フォームごとに自動生成されるアンカーIDを使うため、PDF設定IDや保存済み設定内容は変更されません。

## 購読者確認

購読者リストでは、メールアドレス、言語、登録元PDF、状態、配信カテゴリを確認します。

配信に使う場合は、購読中のメールアドレスのみを対象にしてください。配信停止済みの人へメルマガや販売案内を送らないでください。

## CSVインポート時の tags 入力方法

`tags` 列には、配信カテゴリを `|` 区切りで入力します。

日本語タグ名と英語tagIDのどちらでも入力できます。

例:

```text
新作塗り絵PDF案内|子ども向け塗り絵案内
```

```text
new_pdf|kids
```

区切り記号 `|` を入れ忘れると正しく分割されません。空白が入ってもできるだけ自動判定しますが、基本は下の対応表の名称をコピーしてください。

## メルマガテンプレート

よく使うメルマガ文面はテンプレートとして保存できます。

テンプレートに保存される内容:

- テンプレート名
- 送信対象
- 配信カテゴリ
- 件名
- 本文

保存済みテンプレートは、「このテンプレートを使う」で送信フォームへ反映できます。編集、上書き保存、複製、削除も可能です。テンプレート操作だけでは本送信されません。

## メルマガ送信前の確認手順

1. 送信対象を選ぶ
2. 必要に応じて配信カテゴリを選ぶ
3. 件名と本文を確認する
4. テスト送信する
5. プレビューで対象人数を確認する
6. 件名、本文、対象カテゴリ、対象人数を再確認する
7. 問題ない場合だけ送信実行する

## 本送信前の注意

本送信は実際に購読者へメールを送ります。プレビューを作成しないと送信実行できない設計ですが、送信前には必ず内容と対象人数を確認してください。

全員宛送信は特に慎重に扱ってください。言語条件や配信カテゴリを使って、必要な対象だけへ送る運用を推奨します。

## メルマガ送信ログのクリア

メルマガ送信ログは、メルマガ送信ログ付近の「送信ログをクリア」ボタンから削除できます。

削除されるのはメルマガ送信ログのみです。購読者、PDF設定、メルマガテンプレート、配信カテゴリには影響しません。

操作前には確認ダイアログが表示されます。販売前のテスト送信履歴や運用開始前の確認ログを整理したい場合に使用してください。

## バックアップの考え方

大きな変更前や定期的な保守時には、購読者リストCSVを出力して保管してください。

特に確認しておくもの:

- 購読者リストCSV
- 配信用CSV
- 送信ログCSV
- PDF設定の管理画面内容
- 配布zip

CSVには個人情報が含まれるため、保存場所と共有範囲に注意してください。

## トラブル時の確認ポイント

- PDFリンクがブラウザで直接開けるか
- メールが迷惑メールフォルダに入っていないか
- 送信元メールアドレスとSMTP設定に問題がないか
- reCAPTCHA v3のSite Key / Secret Key / ドメイン設定が合っているか
- CSVの `email` と `lang` が入っているか
- CSVの `tags` が `|` 区切りになっているか
- CSVプレビューで未対応タグやエラーが出ていないか
- 購読者が配信停止状態になっていないか
- メルマガ送信時の送信対象と言語、配信カテゴリが意図通りか
