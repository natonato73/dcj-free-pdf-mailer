# DCJ Free PDF Mailer v1.4.0 メルマガ送信MVPメモ

## 1. 目的

無料PDF配布フォームで集めた購読者に対して、WordPress管理画面から簡単なメルマガを手動送信できるようにする。

## 2. 実装範囲

- 管理画面のメルマガ送信セクション
- 送信対象の選択
  - 全員
  - 日本語購読者
  - 英語購読者
- 件名入力
- 本文入力
- テスト送信先メールアドレス入力
- テスト送信
- 送信前プレビュー
- プレビュー後の送信実行
- 送信結果表示
- 簡易送信ログ保存
- メルマガテンプレート保存、呼び出し、編集、上書き保存、複製、削除
- 配信カテゴリによる購読者タグ付けとメルマガ送信対象の絞り込み

## 3. 対象外

- 予約配信
- HTMLメールエディタ
- 画像添付
- 自動配信
- 外部メール配信サービス連携
- DBテーブル追加

## 4. 送信対象

送信対象は、配信停止ではない購読者のみとする。

既存データでは購読中のステータスを `subscribed` として保存しているため、v1.4.0では `active` と `subscribed` を送信可能な購読者として扱う。

- 全員: 送信可能な購読者すべて
- 日本語購読者: 送信可能かつ `lang = ja`
- 英語購読者: 送信可能かつ `lang = en`

v1.6.0では、上記の言語条件に加えて、配信カテゴリタグで対象者を絞り込める。

- 配信カテゴリ未選択: 従来どおり言語条件だけで対象者を抽出する
- 配信カテゴリを1つ以上選択: 選択カテゴリのいずれかを `tags` に持つ購読者だけを対象にする
- 複数カテゴリ選択時はOR条件とする
- 例: `amazon_books` と `adult` を選んだ場合、どちらか一方でも持つ購読者を対象にする

## 5. 送信ログ

送信ログはWordPress optionに簡易ログとして保存する。

保存内容:

- 送信日時
- 件名
- 送信対象
- 対象件数
- 成功件数
- 失敗件数

DBテーブル追加は行わない。

## 6. 配信カテゴリ・購読者タグ

配信カテゴリは固定定義とし、PDF設定、購読者データ、CSV、メルマガ送信フォーム、メルマガテンプレートで同じタグIDを使う。

| タグID | 表示名 |
| --- | --- |
| `new_pdf` | 新作塗り絵PDF案内 |
| `seasonal` | 季節の塗り絵紹介 |
| `amazon_books` | Amazon書籍紹介 |
| `gumroad_books` | Gumroad書籍紹介 |
| `kids` | 子ども向け塗り絵案内 |
| `adult` | 大人の塗り絵案内 |
| `blog` | ブログ記事紹介 |

PDF設定:

- 管理者がPDF設定の追加・編集フォームで配信カテゴリを複数選択する
- 保存先は各PDF設定配列の `tags`
- 既存PDF設定に `tags` がない場合は空配列相当として扱う
- 公開側の無料PDF登録フォームには配信カテゴリ選択欄を表示しない

購読者タグ:

- 無料PDF申し込み時、メルマガ同意ありの場合だけ、PDF設定の `tags` を購読者データへ追加する
- 新規購読者は `tags` 配列として保存する
- 既存購読者は既存 `tags` とPDF設定の `tags` を統合する
- 既存タグは上書き削除しない
- 同じタグは重複保存しない
- メルマガ同意なしの場合は購読者タグを付与しない
- 購読者データに `tags` がない場合も空配列として安全に扱う

CSV:

- CSVテンプレートに `tags` 列を含める
- `tags` は `new_pdf|seasonal|kids` のような `|` 区切り
- インポート時は有効な英語tagID、または日本語タグ名を英語tagIDへ変換して取り込む
- 日本語タグ名と英語tagIDの混在も許可する
- 子供/子ども、向けの有無、空白混入など最小限の表記ゆれを許可する
- `tags` 列は `|` 区切りを基本とし、区切り忘れや未対応タグはプレビューで確認する
- 既存CSVに `tags` 列がない場合は空タグとして扱う
- `email` / `lang` 必須など既存仕様は維持する
- エクスポート時も `tags` を `|` 区切りで出力する

## 7. メルマガテンプレート

よく使うメルマガ文面は、テンプレート名、送信対象、配信カテゴリ、件名、本文をWordPress optionに保存する。

- テンプレート保存では本送信しない
- テンプレート呼び出しでは送信フォームへ内容と配信カテゴリを反映するだけで、本送信しない
- テンプレート編集ではテンプレート名、送信対象、配信カテゴリ、件名、本文をフォームへ読み込むだけで、本送信しない
- テンプレート更新では同じテンプレートIDの内容を上書きする
- 編集キャンセルではテンプレート、購読者DB、送信ログを変更しない
- テンプレート複製では送信対象、配信カテゴリ、件名、本文をコピーし、テンプレート名末尾に「 コピー」を付けた新規テンプレートを作成する
- テンプレート削除では購読者DBと送信ログを変更しない
- 既存テンプレートに `tags` がない場合は空配列相当として扱う
- DBテーブル追加は行わない

## 8. 確認項目

- メルマガ送信セクションが管理画面に表示される
- 件名・本文未入力時に送信できない
- テスト送信で購読者DBが変わらない
- テンプレート名、送信対象、配信カテゴリ、件名、本文を保存できる
- 保存済みテンプレートが一覧表示される
- 「このテンプレートを使う」で送信対象、配信カテゴリ、件名、本文がフォームに反映される
- テンプレート呼び出しだけでは本送信されない
- 「編集」でテンプレート名、送信対象、配信カテゴリ、件名、本文がフォームに反映される
- 編集中表示と「テンプレートを更新」ボタンが表示される
- 編集保存で同じテンプレートIDの内容を上書きできる
- 編集キャンセルで新規保存状態に戻る
- 「複製」で元テンプレートを変更せず、末尾に「 コピー」が付いた新規テンプレートを作成できる
- テンプレート削除で購読者DBと送信ログが変わらない
- プレビューで件名、本文、送信対象、対象購読者数を確認できる
- プレビューで選択した配信カテゴリ名を確認できる
- 配信カテゴリ未選択時は従来どおり言語条件だけで対象人数が出る
- 配信カテゴリ選択時は、選択カテゴリのいずれかを持つ購読者だけが対象人数に反映される
- 本送信時もプレビュー時と同じ配信カテゴリ条件が使われる
- プレビュー前に本送信できない
- プレビュー表示中に本送信前の注意文が表示される
- 対象購読者数が10件以上の場合に追加の注意表示が表示される
- プレビューをクリアすると、購読者DBと送信ログを変更せず通常入力状態へ戻る
- 送信対象が全員、日本語、英語で切り替わる
- 本送信後に成功件数・失敗件数が表示される
- 本送信後に簡易ログが保存される
- PDF設定の追加・編集で配信カテゴリを保存できる
- 公開側の無料PDFフォームに配信カテゴリ選択欄が出ない
- メルマガ同意ありの無料PDF申し込みで、PDF設定の `tags` が購読者へ追加される
- 同じ購読者が複数PDFを申し込んだ場合、既存タグを残したままタグが追加統合される
- 同じタグが重複保存されない
- メルマガ同意なしの無料PDF申し込みでは購読者タグが付与されない
- 購読者手動追加で配信カテゴリを選択できる
- 購読者一覧に配信カテゴリが日本語ラベルで表示される
- CSVテンプレート、CSVインポート、CSVエクスポートで `tags` を扱える
- 既存のPDF配布、購読者管理、CSV機能に影響がない
